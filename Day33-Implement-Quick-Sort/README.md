# Day33- Implement Quick Sort 

## Problem
Quick Sort is a popular sorting algorithm  It works by selecting an element called a pivot and partitioning the array around it.

## Approach
1. Select the last element as the pivot.
2. Compare each element with the pivot.
3. Move smaller elements to the left side.
4. Place the pivot in its correct position.
5. Recursively sort the left and right subarrays.

## Concepts Learned
- Quick Sort Algorithm
- Divide and Conquer
- Pivot Selection
- Partitioning
- Recursion
- Array Swapping

## Example
Input:
```
int[] arr = {6, 3, 8, 5, 2, 4, 1, 7};
```
Output:
```
1 2 3 4 5 6 7 8
```
