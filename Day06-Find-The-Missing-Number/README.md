## Day 06 – Find the Missing Number

# Problem
Given an array containing `n` distinct numbers from the range `0` to `n`, find the one number that is missing.

# Approach
- Calculate the expected sum using the formula `n * (n + 1) / 2`.
- Calculate the actual sum of all elements in the array.
- Subtract the actual sum from the expected sum to find the missing number.

# Concepts Learned
- Finding a missing number using the mathematical sum formula.
- Calculating the sum of array elements using an enhanced `for` loop.
- Using mathematical logic to solve DSA problems efficiently.
