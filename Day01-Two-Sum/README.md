# Two Sum — Java

My first DSA solution! Find two indices in an array
whose elements add up to a target.

# Example
- Array: [32, 65, 56, 23, 44]
- Target: 100
- Output: Indices 2 and 4

# Approach
1. Use two nested loops to check each pair.
2. The first loop selects the first element.
3. The second loop checks elements after it.
4. If their sum equals the target, it prints the indices.
