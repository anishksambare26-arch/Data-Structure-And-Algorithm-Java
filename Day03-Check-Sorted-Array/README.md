# Day03 - Check if Array is Sorted

## Problem Statement
Check whether Array Is Sorted

Return `true` if the array is sorted, otherwise return `false`.

## 💡 Approach

1. Traverse the array using a `for` loop.
2. Compare each element with the next element.
3. If the current element is greater than the next element, return `false`.
4. If no such pair is found, return `true`.

- Array traversal
